# 언어

Bắp은 **베트남어**(기본), **영어**, **한국어**, **중국어**로 말합니다. 웹 설정(개인화)이나 원형 메뉴 →
설정 → 언어에서 고르세요.

언어를 바꾸면:

- **답변**이 바뀝니다. 시스템 프롬프트가 캐릭터에게 그 언어로 말하라고 합니다.
- **화면**이 바뀝니다. 상태 문구("듣는 중…"), 메뉴 이름, 쉬는 얼굴 아래 날짜 줄(요일, 양력, 음력과
  명절)이 번역됩니다.
- **자막**: 한국어와 중국어는 assets 파티션에 있는 Noto Sans KR/SC 부분 글꼴로 그리며, 대체 글꼴로
  연결됩니다.

데이터 소스는 베트남 것이지만(금 시세, 복권, VnExpress) 캐릭터가 당신의 언어로 설명해 줍니다.

## 언어 추가

언어는 `firmware/data/assistant.json`의 데이터입니다.

```json
{
  "id": "ja",
  "name": "日本語",
  "prompt": "Always speak Japanese with the user...",
  "ui": {
    "Đang lắng nghe...": "聞いています…",
    "Thứ hai": "月曜日",
    "{w} {d}/{m}": "{m}月{d}日 {w}"
  }
}
```

`ui`는 베트남어 UI 문자열을 번역문에 대응시킵니다. 빠진 문자열은 베트남어로 표시됩니다. 날짜
템플릿은 `{w}`(요일), `{d}`, `{m}`, `{ld}`, `{lm}`(음력 일과 월)을 씁니다. 내장 글꼴에 없는 문자는
assets 파티션의 대체 글꼴에 글리프를 추가하세요.
