# FAQ와 문제 해결

### 다른 Wi-Fi에 연결하려면?

휠을 길게 눌러 메뉴 → **설정 → Wi-Fi 설정**을 고르거나 "Wi-Fi 다시 설정해 줘"라고 말하세요. 기기가
**`Bap-XXXX`** 핫스팟을 엽니다. 휴대폰으로 접속해 `http://192.168.4.1`에서 새 네트워크를 고르세요.
연결된 상태라면 웹 설정(시스템 탭)에서 네트워크를 추가할 수도 있습니다.

### 화면에 네트워크를 확인하라고 나와요

기기가 계속 재시도합니다. 공유기가 2.4 GHz인지(ESP32-S3는 5 GHz를 지원하지 않음), 저장된 비밀번호가
맞는지 확인하세요.

### "Gemini rejected the session"

키가 없거나, 틀렸거나, 사용량이 다 됐습니다. `http://bap-xxxx.local` → 시스템 → Gemini에서 새 키를
붙여 넣으세요. 유료 대체 키가 있으면 기기가 알아서 전환합니다.

### 호출어를 못 알아들어요

1미터 정도 거리에서 "Hi Lili"를 또렷하게 말하세요. *야간 방해 금지*는 22:00부터 06:00까지 호출어를
끕니다. 그때는 휠을 누르거나 화면을 두 번 탭하세요.

### 밤에 너무 시끄러워요

야간 모드(기본 켜짐)는 22:00–06:00에 음량을 35%로 제한합니다. 말하는 중에 휠을 돌리거나 메뉴나 웹
설정에서 음량을 정하세요.

### 설정 비밀번호를 잊었어요

휠을 20초 동안 누르세요. 모든 설정(Wi-Fi, 키, 비밀번호 포함)이 기본값으로 돌아갑니다.

### 음악은 어떻게 멈추나요?

화면을 두 번 탭하거나, "음악 꺼 줘"라고 말하거나, 웹 설정에서 정지를 누르세요.

### 원래 펌웨어로 돌아갈 수 있나요?

네. `firmware/restore_stock.sh`가 전체 백업을 다시 씁니다. 백업이 없다면 Seeed 도구로 SenseCraft를 다시
설치하세요. `0x9000`의 공장 키는 그대로입니다.

### 밖에서도 쓸 수 있나요?

설정 페이지는 의도적으로 LAN 전용입니다. Tailscale이나 WireGuard 같은 VPN으로 집 네트워크에 들어가고,
기기를 인터넷에 노출하지 마세요.

### 로그는 어디서 보나요?

USB를 연결해 115200 baud로 시리얼 포트를 열거나, 대화 탭의 대화 기록을 보세요. `/api/perf`가 CPU,
메모리, Wi-Fi 상태를 보여 줍니다.
