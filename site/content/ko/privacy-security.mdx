# 개인정보와 보안

## 중계 서버 없음

기기는 `generativelanguage.googleapis.com`으로 TLS 연결을 열 뿐, 중간에 아무것도 없습니다. Bắp
클라우드도, 계정도, 분석도 없습니다.

## 무엇이, 언제 기기를 떠나나

- **음성**은 대화 중에만 Gemini로 스트리밍됩니다. 호출어, 휠 누르기, 두 번 탭 이후입니다. 30초 동안
  조용하면 세션이 닫힙니다.
- **이미지**는 비서가 카메라 도구(`self.camera.take_photo`)를 호출할 때만 전송됩니다. 사람 인식은
  카메라 자체 AI 칩에서 실행되며 이미지를 보내지 않습니다.
- **도구 요청**은 공개 데이터 소스(Open-Meteo, VnExpress, Vietcombank, PNJ, CafeF, ESPN, Zing MP3,
  라디오 방송국)로 바로 갑니다. 도시는 날씨에 쓰이고, 그 외에 당신에 관한 정보는 보내지 않습니다.
- 직접 추가한 **웹훅**은 당신이 보낸 요청 텍스트를 받습니다.

## API 키

키는 기기의 NVS에 저장되거나 `secrets/GEMINI_API_KEY`에서 펌웨어에 들어갑니다. 브라우저에는 가려진
키(`AIza••••••••xxxx`)만 보입니다. 기기를 손에 넣거나 키를 넣어 빌드한 `xiaozhi.bin`을 가진 사람은 키를
꺼낼 수 있으니, 사용량 제한이 있는 전용 키를 쓰고 빌드한 `.bin`은 공유하지 마세요.

<Callout type="info">
팁: 무료 키를 주 키로, 결제가 켜진 별도 키는 대체용으로만 쓰세요. 기기는 항상 무료 키를 먼저 씁니다.
</Callout>

## 설정 페이지

- LAN 전용입니다. 80번 포트를 인터넷에 열지 말고, 원격 접속에는 VPN을 쓰세요.
- 선택적 비밀번호 (HTTP Basic, 솔트와 반복을 적용한 SHA-256을 NVS에 저장).
- 모든 `POST`에 `X-Bap` 헤더가 필요해 다른 웹사이트의 교차 사이트 폼 공격을 막습니다.

## 플래시와 공장 키

`nvsfactory`(`0x9000`)는 절대 쓰지 않습니다. `firmware/restore_stock.sh`는 SHA-256을 확인한 뒤 전체
백업을 다시 씁니다.

## 기여자를 위해

`secrets/`, `backup/`, `vendor/`, `firmware/build/`, 빌드 로그, 빌드한 `.bin`은 절대 커밋하지 마세요. CI가
푸시마다 gitleaks를 실행합니다. 서드파티 코드는 빌드나 플래시 전에 읽어 봅니다.
