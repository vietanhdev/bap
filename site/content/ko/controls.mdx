# 휠과 터치

![휠과 터치 동작](/diagrams/controls.svg)

## 스크롤 휠

| 상태 | 동작 | 결과 |
| --- | --- | --- |
| 쉬는 중 | 돌리기 | 음량 |
| 쉬는 중 | 두 번 누르기 | 앱 목록 열기. 돌려서 고르고 눌러서 열기 |
| 대화 중 | 돌리기 | 음량 |
| 대화 중 | 누르기 | 듣기 멈춤 또는 재개 |
| 언제든 | 1초 길게 누르기 | 메뉴 열기 (다시 길게 누르면 뒤로) |
| 메뉴에서 | 돌리기 / 누르기 | 이동 / 열기 |
| 언제든 | 빠르게 3번 누르기 | 전원 끄기 |
| 언제든 | 20초 길게 누르기 | 초기화: 모든 설정 삭제 |

## 터치스크린

| 상태 | 동작 | 결과 |
| --- | --- | --- |
| 쉬는 중 | 탭 | 캐릭터가 킥킥 웃어요 |
| 쉬는 중 | 두 번 탭 | 대화 시작 |
| 쉬는 중 | 길게 누르기 | 메뉴 열기 |
| 쉬는 중 | 위에서 아래로 쓸기 | 빠른 설정: 음량, 밝기, Wi-Fi, 야간 방해 금지 |
| 쉬는 중 | 아래에서 위로 쓸기 | 앱 목록 |
| 말하는 중 | 탭 | 말 끊기 (계속 들어요) |
| 대화 중 | 두 번 탭 | 대화 종료 |
| 음악 재생 중 | 두 번 탭 | 음악 정지 |
| 메뉴에서 | 끌기, 또는 위/아래 항목 탭 | 이동. 가운데 항목을 탭하면 열기, 길게 누르면 뒤로 |

## 원형 메뉴

휠(또는 화면)을 길게 누르면 열립니다: **대화, 앱, 라디오, 설정, 전원 끄기**. 테두리의 호가
현재 위치를 알려 주고, 현재 항목은 알약 모양 안에, 이웃 항목은 위아래로 흐리게 보입니다.

**설정**에는 음량·밝기 슬라이더, 언어, 야간 모드·사람 인식·아침 인사·야간 방해 금지·사람 보면 인사
토글, 기기 정보, Wi-Fi, 재시작이 있습니다.

**Wi-Fi**는 주변 네트워크를 보여 줍니다. 하나를 고르고 원형 키보드로 암호를 입력하세요. 키를 탭하거나 (빗나가면 맞는 키로 밀어서), 휠을 돌려 강조를 옮기고 눌러서 입력합니다. 글자를 탭하면 암호가 보이고, 길게 누르면 취소됩니다. 기기는 네트워크를 저장하고 다시 시작해 연결합니다. *휴대폰으로 설정*은 전처럼 `Bap-XXXX` 핫스팟을 엽니다. **전원 끄기**는 확인을 묻습니다.
