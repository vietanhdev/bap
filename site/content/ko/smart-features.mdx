# 카메라와 스마트 기능

Watcher의 카메라에는 자체 AI 칩인 Himax HX6538이 있어 **칩 위에서** 사람 감지를 실행합니다. Bắp은
이것을 작고 사적인 기능에 씁니다. 이미지는 어디로도 전송되지 않고 Gemini 사용량도 들지 않습니다.

| 기능 | 하는 일 | 기본값 |
| --- | --- | --- |
| **사람 인식** | 누군가 나타나면 화면이 켜지고 캐릭터가 반가워해요 | 꺼짐 |
| **아침 인사** | 6시~10시 사이 처음 당신을 보면 인사하고 아침 브리핑(날씨, 음력, 주요 뉴스)을 읽어 줘요. 하루 한 번, *사람 인식* 필요 | 꺼짐 |
| **사람 보면 인사** | 누군가 오면 인사해요 | 꺼짐 |
| **야간 모드** | 22:00–06:00: 화면 어둡게, 음량 최대 35%, 차분한 얼굴(숨쉬기 없음, "zzz" 고정) | 켜짐 |
| **야간 방해 금지** | 22:00–06:00: 호출어가 꺼져서 TV나 대화 소리에 깨지 않아요. 말하려면 화면을 두 번 탭하거나 휠을 누르세요 | 꺼짐 |
| **화면 휴식** | 5분 동안 아무도 없으면 화면이 6%로 어두워지고 얼굴이 멈춰 전력을 아껴요. 터치, 휠, 호출어, 지나가는 사람이 있으면 다시 켜져요 | 켜짐 |
| **배터리 부족** | 충전하라고 알려 줘요 | 켜짐 |

웹 설정(시스템 탭)이나 원형 메뉴 → 설정에서 켤 수 있습니다.

<Callout type="info">
카메라 사진은 비서가 `self.camera.take_photo`를 호출할 때만 Gemini로 갑니다. 예를 들어 *보고 말하기*
앱에서, 또는 "내가 뭘 들고 있어?"라고 물을 때입니다.
</Callout>

## 다른 센서와 하드웨어

- Espressif AFE(소음 억제, 에코 제거)와 기기에서 실행되는 "Hi Lili" 호출어 모델을 쓰는 **마이크 배열**.
- 오프라인 음악용 **SD 카드** (카메라와 SPI 버스를 공유).
- 상태 표시줄에 보이는 **배터리** 잔량과 충전 상태.
