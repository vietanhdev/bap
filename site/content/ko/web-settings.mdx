# 웹 설정과 OTA

모든 Bắp은 **`http://bap-xxxx.local`**에서 설정 페이지를 제공합니다. `xxxx`는 MAC 주소의 마지막 16진수
네 자리입니다(화면에 표시된 IP도 됩니다). 탭 세 개로 된 한 페이지이며 휴대폰에서도 잘 동작합니다.

## 바꿀 수 있는 것

- **대화:** 대화 기록, 글로 말하기 입력창, 빠른 질문 버튼, 라디오 채널, 앱 목록, 타이머와 알람, 메모,
  정지 버튼이 있는 재생 막대.
- **개인화:** 캐릭터와 이름·목소리·성격, 장기 기억, 언어, 도시(날씨와 대기질에 사용).
- **시스템:** 음량과 밝기(바로 적용), 사람 인식, 아침 인사, 야간 방해 금지, 야간 모드, 자동 휴식
  시간, Gemini 키와 모델, Google 검색, 확장(웹훅), 저장된 Wi-Fi, 설정 비밀번호, 기기 상태(가동
  시간, CPU, 내부 RAM, PSRAM, Wi-Fi 신호, 바쁜 작업), 펌웨어 업데이트와 재시작.

**저장** 막대는 무언가 바뀌었을 때만 올라옵니다. 대부분의 설정은 다음 대화부터 적용됩니다.

## 비밀번호

비밀번호를 정하기 전까지는(시스템 탭) 같은 Wi-Fi의 누구나 페이지를 열 수 있습니다. 비밀번호를 정하면
브라우저가 물어봅니다(사용자 이름은 아무거나). 기기는 솔트를 넣고 여러 번 반복한 SHA-256 해시만
저장합니다. 잊어버렸다면 휠을 20초 동안 눌러 기기를 초기화하세요.

## Wi-Fi 펌웨어 업데이트 (OTA)

시스템 탭에서 `xiaozhi.bin`을 고르거나, 컴퓨터에서:

```bash
firmware/ota.sh bap-xxxx.local
```

업데이트는 약 **30초** 걸립니다. 업로드하는 동안 호출어, 카메라 추론, 터치 폴링이 잠시 멈춰서 Wi-Fi와
CPU가 전송에 집중합니다. 이미지가 검증되면 새 슬롯으로 재부팅합니다. Bắp은 요청할 때만 업데이트하므로
대화를 끊지 않습니다.

### 서명된 업데이트

빌드는 직접 만든 RSA-3072 키로 서명됩니다 (`firmware/scripts/ota_key.sh`가
`secrets/ota_signing_key.pem`을 만들고, `build.sh`가 컴퓨터에서 서명합니다). 서명된 펌웨어를 실행
중인 기기는 서명이 없거나, 변조되었거나, 다른 키로 서명된 Wi-Fi 업데이트를 거부하고 현재 버전을
계속 실행합니다. eFuse를 굽지 않으므로 USB 플래시는 계속 가능하며, 키를 잃어버렸을 때도 이 방법으로
교체합니다. 키를 꼭 백업하세요.

## JSON API

| 경로 | 용도 |
| --- | --- |
| `GET /api/config`, `POST /api/config` | 설정 읽기(키는 가려짐)와 저장 |
| `GET /api/status` | 상태, 재생 중인 곡, 가동 시간, 기록, 알람, 버전 |
| `GET /api/perf` | 작업별 CPU와 스택 여유, 힙, 가동 시간, RSSI |
| `POST /api/say` | 말한 것처럼 텍스트 보내기 |
| `POST /api/action` | 기기 동작 (대화, 정지, 휠 이벤트, Wi-Fi 설정, 재부팅) |
| `POST /api/tool` | 도구 직접 호출 |
| `POST /api/app` | 앱 시작 |
| `GET/POST /api/wifi` | 저장된 네트워크 |
| `POST /api/ota` | 펌웨어 업로드 |
| `GET /face`, `GET /screen.jpg` | 얼굴 미리보기, 실시간 화면 캡처 |

<Callout type="warning">
모든 `POST`에는 `X-Bap` 헤더가 필요합니다. 브라우저는 다른 사이트의 폼 전송에 사용자 지정 헤더를 붙일 수
없으므로, 낯선 웹페이지가 기기를 조작할 수 없습니다. 그래도 신뢰할 수 있는 네트워크에서만 쓰고 80번
포트를 인터넷에 열지 마세요. 원격 접속에는 Tailscale이나 WireGuard 같은 VPN을 쓰세요.
</Callout>

## 데스크톱 도우미 (선택)

`tools/bap-desktop`은 기기에 상태 카드를 보내는 작은 Rust 프로그램입니다(`POST /api/notify`).
`--device bap-xxxx.local`이나 `BAP_DEVICE`로 기기를 지정하고, 비밀번호가 있으면 `BAP_PASSWORD`를
설정하세요.
