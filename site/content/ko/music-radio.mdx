# 음악과 라디오

## Zing MP3

곡이나 가수를 말해 보세요. "Hà Nội mùa thu 틀어 줘", "Sơn Tùng 노래". `music.search`가 짧은 목록을
읽어 주고, `music.play`가 곡을 스트리밍하면서 **동기화된 가사**(LRC)를 캐릭터 얼굴 아래에 한 줄씩
보여 줍니다. 음악이 나오는 동안 캐릭터는 편안하게 몸을 흔듭니다.

## 라디오

| 채널 | id |
| --- | --- |
| VOV1 뉴스 | `vov1` |
| VOV2 문화와 생활 | `vov2` |
| VOV3 음악 | `vov3` |
| VOV 하노이 교통 | `vovgt_hn` |
| VOV 호찌민시 교통 | `vovgt_hcm` |
| 하노이 FM 90 | `fm_hanoi_90` |
| 하노이 FM 96 | `fm_hanoi_96` |
| RFI 베트남어 | `rfi` |

"VOV3 틀어 줘"라고 말하거나, 웹 설정의 채널 버튼을 누르거나, 원형 메뉴에서 **라디오**를 고르세요.
MP3/AAC 스트림과 HLS 재생 목록을 모두 지원합니다. 채널 목록은 `assistant.json`(`radio[]`)의 데이터라서
한 줄만 추가하면 채널이 늘어납니다.

## SD 카드

microSD 카드에 `.mp3` 파일을 넣으세요(베트남어 파일 이름도 괜찮습니다. FAT를 UTF-8로 마운트합니다).
"카드에 있는 음악 틀어 줘", "카드에서 Diễm xưa 틀어 줘"라고 말하면 됩니다. 성조 부호와 대소문자를
무시하고 찾기 때문에 "diem xua"로도 `Nhạc/Diễm Xưa - Khánh Ly.mp3`를 찾습니다. 네트워크가 필요 없습니다.

## 멈추기

- 화면을 두 번 탭하세요(한 번 탭하면 안내만 나오니 실수로 음악이 꺼지지 않습니다).
- "음악 꺼 줘"라고 말하거나, 웹 설정의 재생 막대에서 **정지**를 누르세요.
