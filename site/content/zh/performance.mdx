# 性能

以下数字都在真实的 Watcher 上于优化前后实测得到。

![优化前后](/diagrams/performance.svg)

| 指标 | 之前 | 之后 |
| --- | --- | --- |
| 唤醒词到开始聆听 | 2.9 秒 | 1.4–2.3 秒 |
| 与 Gemini 的 TLS 握手 | 1.36 秒 | 约 0.1 秒（会话恢复） |
| Zing MP3 搜索 | 2.5 秒 | 1.0 秒 |
| 天气回答 | 6 秒 | 约 2.7 秒 |
| 聆听表情动画时的 CPU | 19.5% | 6% |
| 播放音乐时的 CPU | 14.7% | 1.3% |
| 固件大小 | 3.83 MB | 3.31 MB（4 MB 分区的 79%） |
| OTA 上传 | 112 秒 | 约 30 秒 |

## 关键改进

- **TLS 会话票据。**`TicketSsl` 按主机缓存会话并在下次连接时提供；Gemini、天气、Zing、电台等所有外部请求都经过它。
- **更快的 ECC。**`MBEDTLS_ECP_FIXED_POINT_OPTIM` 每次完整握手节省约 330 ms，代价约 4 KB RAM。
- **安全的地方用普通 HTTP。**公开的天气和地理编码数据走 HTTP 以省去握手；涉及密钥或个人数据的请求仍走 HTTPS。
- **更少的重绘。**透明度量化为约 11 级，聆听波形分 3 步脉动，夜间表情静止。LVGL 以 25 fps 运行。
- **更小的镜像。**未使用的音频编解码器（FLAC、Vorbis、AMR、ADPCM、ALAC、SBC、LC3、G.711/722）已从编译中移除。
- **OTA。**写入前预先擦除闪存区域；上传期间暂停唤醒词、摄像头推理和触摸轮询。
- **会话恢复。**只有提示词和声音不变时才复用恢复句柄，后续问题可以跳过设置步骤。

## 自己检查

```bash
curl -s http://bap-xxxx.local/api/perf | python3 -m json.tool
```

返回内容包括各任务 CPU 和最小栈余量、当前及最低片内 RAM、PSRAM 余量、运行时间和 Wi-Fi 信号。系统标签页的*设备状态*显示同样的数据。
