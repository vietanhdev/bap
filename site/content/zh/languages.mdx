# 语言

Bắp 会说**越南语**（默认）、**英语**、**韩语**和**中文**。在网页设置（个性化）或圆形菜单 → 设置 → 语言中选择。

切换语言后：

- **回答**会改变：系统提示词要求角色使用该语言；
- **屏幕**会改变：状态文字（"聆听中…"）、菜单名称和休息画面下方的日期行（星期、公历、农历和节日）都会翻译；
- **字幕**：韩文和中文使用 assets 分区中的 Noto Sans KR/SC 子集字体，作为后备字体串接。

数据来源仍是越南本地的（金价、彩票、VnExpress），但角色会用你选择的语言来解释。

## 添加语言

语言是 `firmware/data/assistant.json` 中的数据：

```json
{
  "id": "ja",
  "name": "日本語",
  "prompt": "Always speak Japanese with the user...",
  "ui": {
    "Đang lắng nghe...": "聞いています…",
    "Thứ hai": "月曜日",
    "{w} {d}/{m}": "{m}月{d}日 {w}"
  }
}
```

`ui` 把每条越南语界面文字映射到译文；缺少的文字显示越南语。日期模板使用 `{w}`（星期）、`{d}`、`{m}`、
`{ld}` 和 `{lm}`（农历日和月）。内置字体中没有的文字，请把字形加入 assets 分区的后备字体。
