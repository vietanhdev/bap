# 常见问题与排错

### 如何连接另一个 Wi-Fi？

长按滚轮打开菜单 → **设置 → Wi-Fi → 查找网络**，选择网络并直接在设备上输入密码。也可以选 **用手机设置**，或说"重新设置 Wi-Fi"。设备会开启 **`Bap-XXXX`** 热点；用手机连接后在
`http://192.168.4.1` 选择新网络。仍在线时，也可以在网页设置（系统标签页）中添加网络。

### 屏幕提示检查网络

设备会自动重试。请确认路由器开启了 2.4 GHz（ESP32-S3 不支持 5 GHz），并且保存的密码正确。

### "Gemini rejected the session"

密钥缺失、错误或额度用完。打开 `http://bap-xxxx.local` → 系统 → Gemini，粘贴新的密钥。有付费备用密钥时设备会自动切换。

### 听不到唤醒词

为了省电，语音唤醒**默认关闭**：先在设置页面或滚轮菜单中打开*语音唤醒*，再在约一米远处清楚地说 "Hi Lili"。*夜间免打扰*会在 22:00 到 06:00 关闭唤醒词，这时请按滚轮或双击屏幕。

### 夜里声音太大

夜间模式（默认开启）在 22:00–06:00 把音量限制在 35%。说话时转动滚轮，或在菜单、网页设置中调整音量。

### 忘了设置页密码

长按滚轮 20 秒：设备会把所有设置（包括 Wi-Fi、密钥和密码）恢复为默认值。

### 怎么停止音乐？

双击屏幕、说"停止音乐"，或在网页设置中点停止。

### 能恢复原厂固件吗？

可以。`firmware/restore_stock.sh` 会写回完整备份。没有备份时，用 Seeed 的工具重新安装 SenseCraft；`0x9000`
的出厂密钥完好无损。

### 出门在外能用吗？

设置页有意设计为仅限局域网。请用 Tailscale 或 WireGuard 等 VPN 连回家里的网络；不要把设备暴露到互联网。

### 日志在哪里看？

接上 USB，以 115200 波特率打开串口，或查看聊天标签页里的对话记录。`/api/perf` 显示 CPU、内存和 Wi-Fi 状态。
