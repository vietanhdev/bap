# 旋钮与触摸

![滚轮与触摸操作](/diagrams/controls.svg)

## 滚轮

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 休息中 | 转动 | 音量 |
| 休息中 | 双击 | 打开应用列表；转动选择，按下打开 |
| 对话中 | 转动 | 音量 |
| 对话中 | 按下 | 暂停或继续聆听 |
| 任意 | 长按 1 秒 | 打开菜单（再次长按返回） |
| 菜单中 | 转动 / 按下 | 移动 / 打开 |
| 任意 | 快速按 3 次 | 关机 |
| 任意 | 长按 20 秒 | 恢复出厂：清除所有设置 |

## 触摸屏

| 状态 | 操作 | 结果 |
| --- | --- | --- |
| 休息中 | 单击 | 角色咯咯笑 |
| 休息中 | 双击 | 开始对话 |
| 休息中 | 长按 | 打开菜单 |
| 休息中 | 从顶部向下滑 | 快捷设置：音量、亮度、Wi-Fi、夜间免打扰 |
| 休息中 | 从底部向上滑 | 应用列表 |
| 说话中 | 单击 | 打断（继续聆听） |
| 对话中 | 双击 | 结束对话 |
| 播放音乐中 | 双击 | 停止音乐 |
| 菜单中 | 拖动，或点上方/下方的项 | 移动；点中间项打开；长按返回 |

## 圆形菜单

长按滚轮（或屏幕）打开：**聊天、应用、电台、设置、关机**。边缘的弧线指示当前位置，当前项位于胶囊中，
相邻项在上下方淡出。

**设置**包括音量和亮度滑块、语言、夜间模式、有人感知、早安问候、夜间免打扰、见人问好等开关，以及设备信息、
Wi-Fi 和重启。

**Wi-Fi** 列出周围的网络。选一个，在圆形键盘上输入密码：点按按键（点偏了可滑到正确的键），或转动滚轮移动高亮、按下输入。点文字可显示密码，长按取消。设备保存网络后重启并连接。*用手机设置* 和以前一样开启 `Bap-XXXX` 热点。**关机**会要求确认。
